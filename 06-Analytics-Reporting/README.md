# 06 - Analytics & Reporting

Thư mục chứa báo cáo phân tích và theo dõi hiệu quả SEO.

## Cấu trúc

| Thư mục | Mô tả | Tần suất |
|---------|-------|---------|
| `weekly-reports/` | Báo cáo tuần (ranking, traffic overview) | Hàng tuần |
| `monthly-reports/` | Báo cáo tháng đầy đủ + recommendations | Hàng tháng |
| `ranking-tracking/` | Theo dõi thứ hạng từ khóa | Hàng tuần |
| `traffic-analysis/` | Phân tích traffic (organic, referral, ...) | Hàng tháng |
| `conversion-tracking/` | Theo dõi chuyển đổi từ organic | Hàng tháng |

## Quy ước đặt tên
- Weekly: `weekly_YYYY-WNN.md` (ví dụ: `weekly_2026-W09.md`)
- Monthly: `monthly_YYYY-MM.md`
- Ranking: `ranking_YYYY-MM-DD.csv`
