# 08 - Tools Config

Thư mục chứa cấu hình và hướng dẫn sử dụng các công cụ SEO.

## Cấu trúc

| Thư mục | Mô tả |
|---------|-------|
| `google-search-console/` | Cấu hình GSC, hướng dẫn sử dụng |
| `google-analytics/` | Cấu hình GA4, custom events, goals |
| `ahrefs-semrush/` | Config, saved reports, exported data |
| `screaming-frog/` | Crawl configuration profiles |

## Lưu ý bảo mật
- KHÔNG lưu API keys, passwords, tokens trực tiếp trong repo
- Sử dụng file `.env` (đã thêm vào `.gitignore`) cho thông tin nhạy cảm
- Chỉ lưu config templates và hướng dẫn
