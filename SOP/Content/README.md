# SOP - Quy trình Content

## 1. Quy trình tạo Content Brief
- Nhận keyword cluster từ SEO Analyst
- Phân tích SERP top 10 cho primary keyword
- Xác định content type phù hợp (blog, pillar, landing page)
- Outline heading structure (H1, H2, H3)
- Liệt kê các điểm cần cover (subtopics, questions)
- Xác định word count target
- Ghi chú internal link opportunities
- Đặt deadline cho writer

## 2. Quy trình viết Content
- Đọc kỹ content brief trước khi viết
- Viết theo outline đã duyệt
- Sử dụng ngôn ngữ tự nhiên, tránh keyword stuffing
- Đảm bảo E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)
- Thêm data, statistics, examples cụ thể
- Viết CTA rõ ràng
- Self-review trước khi submit

## 3. Quy trình Review & Edit
- Editor review nội dung (accuracy, quality, tone)
- Kiểm tra SEO on-page (title, meta, headings, keyword density)
- Kiểm tra internal/external links
- Kiểm tra hình ảnh và alt text
- Proofread lỗi chính tả, ngữ pháp
- Feedback cho writer nếu cần chỉnh sửa

## 4. Quy trình Publishing
- Upload lên CMS
- Kiểm tra formatting, hình ảnh, links
- Set featured image và excerpt
- Chọn category và tags phù hợp
- Publish và submit URL lên GSC
- Cập nhật content calendar
- Share trên social media (nếu có)

## 5. Content Calendar
- Lên lịch đăng bài hàng tháng
- Cân bằng giữa các content types
- Đồng bộ với campaign marketing
- Review và điều chỉnh hàng tuần

## 6. Quy ước đặt tên file
- Content brief: `brief_YYYY-MM-DD_[keyword-slug].md`
- Draft: `draft_v[N]_YYYY-MM-DD_[keyword-slug].md`
- Published: `pub_YYYY-MM-DD_[keyword-slug].md`
