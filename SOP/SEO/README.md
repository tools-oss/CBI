# SOP - Quy trình SEO

## 1. Quy trình nghiên cứu từ khóa
- Thu thập seed keywords từ khách hàng/stakeholder
- Mở rộng từ khóa bằng Ahrefs/SEMrush/Google Keyword Planner
- Phân nhóm từ khóa theo topic cluster
- Xác định search intent cho từng nhóm
- Đánh giá keyword difficulty và search volume
- Ưu tiên từ khóa theo ma trận: Volume x Difficulty x Business Value

## 2. Quy trình tối ưu On-Page
- Viết title tag (50-60 ký tự, chứa primary keyword)
- Viết meta description (150-160 ký tự, có CTA)
- Cấu trúc heading: 1 H1 duy nhất, H2-H3 logic
- Tối ưu URL slug (ngắn gọn, chứa keyword)
- Thêm internal link (tối thiểu 3-5 link/bài)
- Thêm schema markup phù hợp (Article, FAQ, HowTo, ...)
- Tối ưu hình ảnh (alt text, WebP, lazy load)

## 3. Quy trình Technical SEO
- Audit site hàng tháng bằng Screaming Frog
- Kiểm tra Core Web Vitals hàng tuần
- Cập nhật sitemap.xml khi có bài mới
- Review robots.txt hàng quý
- Kiểm tra lỗi 404, redirect chains, broken links
- Đảm bảo mobile-friendly và HTTPS

## 4. Quy trình Link Building
- Audit backlink profile hàng tháng
- Xác định target sites cho outreach
- Gửi email outreach theo template chuẩn
- Theo dõi và cập nhật trạng thái outreach
- Disavow link spam/toxic hàng quý

## 5. Quy trình báo cáo
- Báo cáo tuần: ranking changes, traffic overview
- Báo cáo tháng: full report + recommendations
- Dashboard real-time trên GA4/GSC
