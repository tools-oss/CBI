# 04 - Technical SEO

Thư mục chứa tài liệu và báo cáo SEO kỹ thuật.

## Cấu trúc

| Thư mục | Mô tả | Tần suất |
|---------|-------|---------|
| `site-audit/` | Báo cáo audit tổng thể | Hàng tháng |
| `crawl-reports/` | Báo cáo crawl Screaming Frog | Hàng tháng |
| `sitemap/` | File sitemap.xml và config | Khi có thay đổi |
| `robots-txt/` | Cấu hình robots.txt | Hàng quý |
| `page-speed/` | Báo cáo tốc độ trang | Hàng tuần |
| `core-web-vitals/` | Metrics LCP, FID, CLS | Hàng tuần |
