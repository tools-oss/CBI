# 05 - Link Building

Thư mục quản lý chiến lược xây dựng backlink.

## Cấu trúc

| Thư mục | Mô tả |
|---------|-------|
| `backlink-audit/` | Báo cáo backlink profile hiện tại |
| `outreach-templates/` | Mẫu email outreach |
| `guest-post-tracking/` | Bảng theo dõi guest post (status, URL, DA, ...) |
| `disavow-list/` | Danh sách link cần disavow gửi Google |

## Quy ước đặt tên
- Audit: `backlink-audit_YYYY-MM.csv`
- Guest post tracking: `guest-post_YYYY-MM.csv`
- Disavow: `disavow_YYYY-MM-DD.txt`
