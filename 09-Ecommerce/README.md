# 09 - Ecommerce & Dropship

Thư mục chứa toàn bộ dữ liệu nghiên cứu sản phẩm, phân tích niche, nhà cung cấp và tính lợi nhuận cho hoạt động ecommerce/dropship.

## Cấu trúc

| Thư mục | Mô tả | Người phụ trách |
|---------|-------|----------------|
| `product-research/` | Báo cáo phân tích sản phẩm chi tiết | Ecommerce Analyst |
| `niche-analysis/` | Đánh giá và xếp hạng niche | Ecommerce Analyst |
| `supplier-list/` | Cơ sở dữ liệu nhà cung cấp | Ecommerce Analyst |
| `profit-calculator/` | Báo cáo tính lợi nhuận | Ecommerce Analyst |
| `trending-products/` | Snapshot sản phẩm đang trending | Ecommerce Analyst |

## Quy ước đặt tên file
- Product research: `product_YYYY-MM-DD_[product-slug].md`
- Niche analysis: `niche_YYYY-MM-DD_[niche-slug].md`
- Supplier list: `supplier_YYYY-MM-DD_[supplier-name].md`
- Profit calculator: `profit_YYYY-MM-DD_[product-slug].md`
- Trending products: `trending_YYYY-WNN.md`
