# 03 - On-Page SEO

Thư mục chứa tài liệu và checklist tối ưu on-page.

## Cấu trúc

| Thư mục | Mô tả |
|---------|-------|
| `title-meta-tags/` | Danh sách title tag & meta description cho các trang |
| `heading-structure/` | Tài liệu cấu trúc heading chuẩn |
| `internal-linking/` | Chiến lược và bản đồ internal link |
| `schema-markup/` | Code snippets structured data (JSON-LD) |
| `image-optimization/` | Checklist tối ưu hình ảnh |

## Checklist On-Page cơ bản
- [ ] Title tag chứa primary keyword, 50-60 ký tự
- [ ] Meta description có CTA, 150-160 ký tự
- [ ] 1 H1 duy nhất chứa primary keyword
- [ ] H2/H3 logic, chứa secondary keywords
- [ ] URL slug ngắn gọn, chứa keyword
- [ ] Internal links: tối thiểu 3-5 link/bài
- [ ] External links: 1-3 link tới nguồn uy tín
- [ ] Hình ảnh có alt text mô tả
- [ ] Schema markup phù hợp
