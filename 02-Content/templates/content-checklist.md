# Content Publishing Checklist

## Trước khi viết
- [ ] Đã đọc kỹ content brief
- [ ] Đã nghiên cứu top 5-10 kết quả SERP
- [ ] Đã hiểu rõ search intent

## Trong khi viết
- [ ] Viết theo outline đã duyệt
- [ ] Primary keyword xuất hiện trong H1, first paragraph, conclusion
- [ ] Secondary keywords phân bố tự nhiên trong bài
- [ ] Đoạn văn ngắn (3-4 câu/đoạn)
- [ ] Có bullet points, numbered lists khi phù hợp
- [ ] Thêm data/statistics có nguồn
- [ ] Hình ảnh minh họa có alt text
- [ ] Internal links (3-5 links)
- [ ] External links tới nguồn uy tín (1-3 links)
- [ ] CTA rõ ràng

## Trước khi publish
- [ ] Title tag: 50-60 ký tự, chứa keyword
- [ ] Meta description: 150-160 ký tự, có CTA
- [ ] URL slug ngắn gọn, chứa keyword
- [ ] Heading structure logic (H1 > H2 > H3)
- [ ] Không lỗi chính tả, ngữ pháp
- [ ] Schema markup đã thêm
- [ ] Featured image đã set
- [ ] Category và tags phù hợp
- [ ] Mobile preview OK

## Sau khi publish
- [ ] Submit URL lên Google Search Console
- [ ] Cập nhật content calendar
- [ ] Share social media (nếu có)
- [ ] Thông báo cho team
